# 設定の不足

## 扱うこと

道具が `NotionAuthError`・404・403 を返したとき、公式MCPのツールが見つからないとき、どの設定の不足によるものか

## 答え方と理由

### 0. 判断全体

なし

### 1. `NotionAuthError` は、`.env` か `NOTION_TOKEN` が無い

`NotionAuthError`（スクリプトでは `NOTION_TOKEN is not set`）は、起動フォルダの `.env`、またはその中の `NOTION_TOKEN` が無い。 README の「セットアップ」の「Notionの準備」を案内する。

1. 記録なし

### 2. あるはずの所で404なら、Integrationが接続されていない

あるはずのページ・データソースで404が返ったら、そのページにIntegrationが接続されていない。 README の「セットアップ」の「Notionの準備」を案内する。

1. 記録なし

### 3. コメントで403か空なら、コメントの権限が無い

コメントの取得・返信で403、または中身の無い結果が返ったら、Integrationのコメントの権限が無い。 README の「セットアップ」の「コメントに答えてもらうときの準備」を案内する。

1. 記録なし

### 4. 公式MCPのツールが無ければ、公式MCPが接続されていない

公式MCPのツール（`notion-get-users` など）が見つからなければ、公式MCPが接続されていない。 3と同じ見出しを案内する。

1. 記録なし

### 5. 設定は補わない

設定は補わない。 トークンを探したり作ったりせず、本人に作ってもらう。

1. 記録なし

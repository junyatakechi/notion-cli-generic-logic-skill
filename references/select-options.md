# selectの選択肢

## 扱うこと

選択肢を入れ替える・改名する・色を変えるとき、どう進めるか

## 答え方と理由

### 0. 判断全体

なし

### 1. 選択肢の一覧は、送った集合がすべて

選択肢の一覧は、差分ではなく「送った集合がすべて」。 一覧から外した選択肢は消え、その選択肢を持っていた行の値はエラーも警告もなく空になる。 DDL（`ALTER COLUMN ... SET SELECT(...)`）でも REST の `PATCH` でも同じ。

1. （原因）1行だけ使われている選択肢を一覧から外して実測したところ、その行の値は `None` になった。2026-08-30に2,311件のカテゴリを壊した事故と同じ挙動。（発生日：記録なし）

### 2. 入れ替えは、足す・振り直す・確かめる・外すの順

選択肢を入れ替えるときは、必ずこの順で行う。
| 順 | すること |
|---|---|
| 1 | 新しい選択肢を足すだけ（古い選択肢は一覧に残したまま） |
| 2 | 行を新しい選択肢へ振り直す |
| 3 | 古い選択肢が0件になったことをクエリで確かめる |
| 4 | 0件を確かめてから、古い選択肢を一覧から外す |

1. （原因）あるDBの選択肢の再編で、この順序により数十件を無傷で移行した。逆順だと、外した選択肢を持っていた行が空になる。（発生日：2026-09-13）

### 3. 改名は、値を書き換えて行う

選択肢を改名したいときは、値を書き換える。 選択肢は書けば自動で生えるので、新しい名前を全行へ書いてから、古い選択肢を一覧から外す。この順番を逆にしない。`select.options` を `id` 付きで渡して名前を書き換えない。黙って捨てられる。

1. （原因）選択肢の改名は通らない。 `select.options` を `id` 付きで渡しても、名前の変更だけが黙って捨てられる。先に古い選択肢を消すと、値が空になってから書き直すことになり、途中で止まったとき何が入っていたか分からなくなる。（発生日：2026-09-14）

### 4. 1件だけを一覧に入れて送らない

1つの選択肢を直すつもりで、その1件だけを一覧に入れて送らない。 他の選択肢が全部消える。

1. 記録なし

### 5. 載せ直す選択肢は、今の色のまま書く

一覧に載せ直す既存の選択肢は、現在の色をそのまま書く。 色を変えたいなら画面で変える。

1. （原因）既存の選択肢に違う色を指定すると、`Cannot update color of select with name: <名前>`（`id` 指定なら `with id: <id>`）で400になる。色の重複指定は通るので、移行の途中で新旧が同じ色でも問題ない。消した選択肢を作り直すと、色は自動で割り当て直される（`purple` が `brown` になった）。（発生日：2026-09-14）

   | 送ったもの | 結果 |
   |---|---|
   | `{"id": 既存, "name": "新しい名前"}` | 無反応（成功レスポンス・名前は変わらない） |
   | `{"id": 既存, "color": "別の色"}` | 400 |
   | 一覧から選択肢を省く | その選択肢が消える |
   | 選択肢に無い値をページへ書く | 選択肢が自動で生える |

   色の変更は400を返すので、Notionは一覧を読んで検証している。それでも名前の変更だけはエラーにもならず消える。だから「成功したのに変わっていない」という形でしか気づけない。

### 6. `ALTER COLUMN ... SET SELECT` を使わない

`ALTER COLUMN "X" SET SELECT(...)` は使わない。 名前でしか指定できないぶん、書き落とした選択肢の値が黙って消える危険が `PATCH` より高い。

1. 記録なし

### 7. 選択肢を変える `PATCH` には、説明も同送する

選択肢を変える `PATCH` には、その列の `description` も同送する（[列の説明と改名](column-description.md)）。

1. 記録なし

## 道具

`query_data_source`（件数の確認・振り直す行の取得）・`update_page`（値の書き換え）・`notion_request("PATCH", f"/data_sources/{id}", ...)`（一覧の更新）。

答え方3：

```python
# 1. 全行の値を新しい名前で書き直す(選択肢は自動で生える)
for page in query_data_source(ds, {"page_size": 100}):
    ...
    update_page(page["id"], {"properties": {"対象": {"select": {"name": NEW[old]}}}})
# 2. 使用件数が0になったのを確かめてから、古い選択肢を一覧から外す
```
